# 西安文化介绍网站

这是一个基于 HTML5 和 CSS3 开发的西安文化介绍网站。网站以“大唐盛世”为设计主题，结合现代前端技术展示西安的历史深度、民俗魅力及旅游风采。

## 功能特点

- **沉浸式视觉体验**：采用深红与金色的经典配色，搭配 AI 生成的高清西安特色图景。
- **语义化结构**：严格遵守 HTML5 标准，确保代码清晰、易于维护且对 SEO 友好。
- **混合布局设计**：巧妙融合了传统的竖排文字排布（Vertical Layout）与现代的横排内容块，体现古今交融之感。
- **响应式设计**：针对不同屏幕尺寸（手机、平板、桌面）进行了适配，确保在任何终端都有一致的浏览体验。
- **动态交互**：页面包含平滑的淡入加载效果和卡片悬停反馈，增强用户交互感。

## 页面说明

1.  **首页 (index.html)**：通过宏大的叙述揭露西安作为十三朝古都的历史底蕴。
2.  **民俗活动页 (activities.html)**：重点介绍秦腔、皮影戏等非物质文化遗产。
3.  **旅游指南页 (travel.html)**：为游客提供必打卡景点及关中地道美食的实用建议。

## 技术栈

- HTML5 (Semantic Elements)
- CSS3 (Flexbox, Grid, Animations, Vertical writing mode)
- Google Fonts (Noto Serif SC)
- AI Generated Images

## 使用说明

1. 克隆或下载本项目至本地。
2. 在浏览器中打开 `index.html` 即可开始浏览。
3. 通过顶部导航栏在不同板块间自由切换。

# 路线提醒编排器（新增子系统）

在静态文化站之外，新增一套可运行的路线提醒编排器：**管理网页**把施工、班次与适行限制标到具体线段；**服务 API** 计算时空影响；**关系库**（SQLite）分别保存路线几何、规则与公告修订。

## 运行

```bash
python3 -m server.app --port 8000     # 首次启动自动建库并写入演示数据
# 用户端  http://127.0.0.1:8000/planner.html
# 管理端  http://127.0.0.1:8000/admin.html
python3 -m unittest discover -s tests -v   # 验收测试（13 项）
```

## 设计要点

- **局部施工与路线实际片段求交**：公告几何（多边形/线+缓冲/点+缓冲）与当前版本片段折线精确求交，交点即页面展示的"影响位置"。不按景区同名匹配、不用包围框近似（`server/geometry.py`，含"包围框重合但几何不相交不误伤"的验收用例）。
- **方向与生效时段参与判断**：公告可限定正向/反向/双向（相对片段行进方向），时段支持绝对窗口与每日窗口（含 22:00-06:00 跨日）；按**到达片段的时刻**判定是否命中。
- **两种规划策略对比**：`POST /api/plan` 带 `compare:true` 同时返回——
  - `reachable_then_filter`：先求可达路线再筛人群与约束（最短路径事后才发现违规，需返工）；
  - `constrained_search`：人群与约束直接进入搜索（边过滤式 Dijkstra），直接给出可行解或**无解原因集合**。
- **冲突解释与无解原因集**：老人（坡度≤8%、无台阶）、儿童/婴儿车（无台阶、不临水无护栏）、轮椅（无台阶、坡度≤6%、净宽≥0.9m）各有可判依据；无解时逐层放松约束（人群→公告→待核），枚举所有位于可行放松路径上的阻断因素并附依据。
- **来源矛盾 → 待核**：上报与公告/上报之间相互矛盾时记为 `pending_review`，规划默认避开并列入"缺信息范围"，**绝不自行拼接成通行保证**。
- **验收场景**（`tests/test_acceptance.py`）：跨日施工、撤销公告迟到（`effective_at` 与 `received_at` 分离，空档期计划重连时标记）、路线改线（版本化片段，影响自动重算）、旧离线计划重连（快照比对 + 重新确认清单）、一条路段同时命中多项提醒。
- **版本化确认**：`acks(user_id, alert_id, rev)`——已查看确认只对应当时版本；公告出新修订后旧确认失效，确认旧版本号会被 409 拒绝，页面提示"已有新版，需重新确认"，不会因打开过旧提醒而隐藏新变化。
- **打印计划**：附生成时刻、各来源最近上报时间（超期标记）与缺信息范围（待核项、超期来源），声明打印件仅反映生成时刻的数据版本。
- **定位被拒降级**：定位仅用于就近选点；拒绝授权或不可用时提示并聚焦手动地点选择，查询完全不受影响。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/graph` `/api/places` | 当前版本路网与地点 |
| GET | `/api/impacts?at=` | 时空影响（求交+方向+时段） |
| POST | `/api/plan` | 规划（`compare` 返回双策略对比；`save` 存离线计划） |
| POST | `/api/alerts` | 发布提醒（几何锚定所选线段） |
| POST | `/api/alerts/{id}/revisions` `/revoke` | 新修订 / 撤销（迟到撤销可识别） |
| POST | `/api/alerts/{id}/ack` | 版本化确认 |
| POST | `/api/reports` | 来源上报（自动矛盾检测） |
| GET | `/api/conflicts` | 待核冲突 |
| POST | `/api/routes/{id}/reroute` | 改线（版本+1） |
| GET | `/api/plans/{id}` `/refresh` | 打印数据（新鲜度+缺信息）/ 重连比对 |
